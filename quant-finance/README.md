# Quant Finance Projects

Course project notebooks and data files.

## Contents

- `notebooks/` contains the investment weights, CAPM, firm characteristic return prediction, factor calculation, and time series analysis notebooks.
- `data/` contains the input CSV and Excel workbook used by the notebooks.

`notebooks/Assignment II Multifactor Model and Factor Extraction.ipynb` is the write-up for 과제 II (다요인 모형과 요인추출): Fama-MacBeth regressions of stock returns on firm characteristics (contemporaneous vs. 16-month lagged) and High-minus-Low hedge portfolios, following Han, Lee and Kang (2020). It reads `data/QuantDataR.xlsx` by relative path, so it runs locally as well as in Colab.

The other notebooks were authored for Google Colab and refer to files in `/gdrive/MyDrive/QuantFinance/`.
